# psychscanner

[PsychScanner: A tool to bridge natural psychology with the artificial intelligence.](https://docs.google.com/presentation/d/1X6IQNQOaf0nH-nFBU2EQedfQF_81r5z1XYtxeamFWY8/edit?usp=sharing)

Tested on Python 3.11.11

![image](docs/psychscanner.png)

Note: The package is under rapid development. Contributions are welcome.


* Automates laboratory cognitive tasks with LLMs.
* Cognitive tasks can be implemented with different levels of conversation history.
* Configurable trial feedback/message for LLMs’ responses.
* Run LLMs with different persona to do the tasks.


## Installation

<!-- start docs-include-installation -->

```sh
uv tool install psychscanner
```
or

```sh
pip install -e .
```
