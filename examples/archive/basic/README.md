# Basic Examples

Simple examples to get started with PsychScanner.

## Files

- `simple_survey.py` - Basic survey implementation

## Running

psychscanner isn't published on PyPI — install from source (see [Installation](https://psychscanner.readthedocs.io/en/latest/installation/)):

```bash
git clone https://github.com/saurabhr/psychscanner.git
cd psychscanner
uv pip install -e .

# Run the example
python simple_survey.py
```

## What You'll Learn

- Creating an ExpCard
- Running a basic survey
- Viewing results
- Using different LLM providers
